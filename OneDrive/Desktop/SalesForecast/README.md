#  Sales Analytics & Prediction Dashboard

##  Project Overview

This project focuses on analyzing sales data to identify important business trends, relationships, and patterns. The project combines Exploratory Data Analysis (EDA), data visualization, machine learning, and an interactive web-based dashboard.

The objective is to understand the factors influencing sales performance and build a machine learning model that can be used for sales prediction.

---

##  Objectives

- Analyze historical sales data.
- Understand the distribution and patterns of sales.
- Identify relationships between product and outlet-related variables.
- Perform exploratory data analysis using visualizations.
- Compare machine learning models for sales prediction.
- Evaluate model performance using appropriate regression metrics.
- Present the findings through a client-facing analytics dashboard.
